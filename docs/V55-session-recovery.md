# V55 会话恢复重试

代码审计发现：启动 getSession 遇到暂时错误后，原先 online/visibility/周期同步只调用数据同步；guest 状态直接返回，不重新恢复会话。

现在对恢复错误保留重试状态；联网、回到前台、前台15秒巡检以及手动恢复按钮会重新调用 SDK getSession。同一时刻多个恢复请求复用一个 Promise，不自行重复使用 refresh token。已成功确认无会话时不无限自动重试，也不尝试匿名登录或硬编码密码。

getSession 报错时不切换已有账号、不删除本机记录；如果启动时仍为访客，访客编辑保持原账号隔离，不自动搬进恢复账号。需要用户明确采用本机数据时仍走已有确认流程。云端身份继续由 getUser、RLS 与 RPC 校验。

认证日志聚合的检查窗口为2026-10-17 20:00至10-18 20:00 Brisbane：看到刷新成功，没有认证请求失败；这不能证明用户设备从未丢失存储或所有时间段无错误。未公开账号、IP、令牌或训练数据。无 SQL、无权限变更。
