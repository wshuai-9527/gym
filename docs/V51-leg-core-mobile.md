# V51：腿＋核心与手机适配

用户目标：每周6次力量，腿部保持基础力量、不过度追求腿围，核心以腹肌训练为目标；器械简单。

## 起始模板（每次）

| 动作         | 记录         | 器械               |
| ------------ | ------------ | ------------------ |
| 坐凳深蹲     | 2×8–12次     | 稳定训练凳，先自重 |
| 自重臀桥     | 2×10–15次    | 垫子               |
| 仰卧小幅卷腹 | 2×10–15次    | 垫子               |
| 死虫式       | 2×6–10次/侧  | 垫子               |
| 屈膝侧桥     | 2×15–30秒/侧 | 垫子               |

每次腿部4组、核心6组，两轮分别8/12个记录组。单侧按每侧记录一次，不能把记录秒数当作包含双侧与休息的总训练时长。组数是据用户目标给出的起始量，不是机构统一处方或最低有效阈值。不承诺绝对不长腿围，亦不保证动作零损伤。

腿部基础休息60–90秒，核心45–60秒；动作不能控制或呼吸未恢复时多休息。卷腹不拉颈、不甩动；死虫式避免腰拱起；侧桥先屈膝、肘在肩下。躯干稳定动作不追求力竭，先质量再次数/时间。锐痛或已有伤病时应停止相关动作并评估。

腹肌训练与可见腹肌不是一回事；体脂、腹肌厚度及个体差异都影响外观。不能依赖练腹保证局部减脂，也不设置统一体脂百分比或极端饮食目标。
