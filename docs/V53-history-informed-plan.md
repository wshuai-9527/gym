# V53：依据实际记录预填，不把减少腿部总量等同于自重

用户指出已有负重训练基础，前两版根据“简单器械/不追求腿围”直接采用自重过于泛化。本版保留负重保加利亚分腿蹲、地面哑铃臀桥，每次各2组；卷腹、平板、屈膝侧桥各2组。既有历史数据不改写，无新SQL。

## 历史参考规则

- 从当前账号有效记录中找最近一次同动作，排除未来记录；不是历史最大重量。
- 展开压缩组，逐组预填重量、次数、秒数；不把前两组都替成最后一组重量。
- 显示来源日期与原始组值。超过28天仅展示参考，不自动预填；这是保守的产品阈值，不是生理学训练中断标准。
- 不在单臂/双臂、负重/自重等不同变式之间转移负荷。不擅自乘2或更改历史计量口径。
- 没有RIR、疼痛、动作质量信息时，不自动提高负荷或把预填值称为安全处方；用户依据本次实际完成修改。
- 已有本次草稿优先于历史预填，不覆盖本次编辑。V49/V50/V51/V52有进度草稿继续原映射；空草稿切新版本。

腿部负荷以近期本人训练为参考，减少组数控制量；腹部时长也展示本人最近数据，不统一重置成新手。没有同动作历史时明确空缺，重量不凭空生成。个人真实重量仅来自账号数据，不硬编码到公开仓库；自动化测试使用合成记录。
