# V56 实用性与计划复核

## 判断

当前App具备记录、版本化草稿、离线待传、账号隔离、历史编辑/软删除恢复、Brisbane日历和三日报告。测试可验证行为，不等于iPhone后台、键盘、存储回收的真机验证；不能称为完美或医疗安全保证。

Push/Pull每周两轮的安排包含水平推、垂直推、水平拉、垂直拉和肩臂辅助。胸部计划约10组/周、拉类12组/周，是可调整起点，不把所有肌群复合参与机械累计成有效组。六练是用户目标而非适用每个人的最低标准。

腿日每次分腿蹲2组、臀桥2组和核心6组，保留本人已建立的负重基础。它是低量腿部/核心偏好下的取舍，不是全面下肢均衡：腘绳肌与小腿直接训练不足，臀桥不是完整替代，篮球也不等于抗阻训练。分析页明确说明可选用熟练哑铃RDL替换一轮臀桥的思路，不自动改动作或搬用臀桥重量。没有动作能承诺零损伤，疼痛、技术和恢复仍需本人确认。

## 本轮改动

- 主项一键休息150秒，臀桥/孤立默认90秒、核心60秒；分腿蹲说明按两侧完成一轮后休息，左右换侧按需要休息。推荐起点不是硬性上限。
- 训练页浮动倒计时与计时页共用已持久化截止时间；不因开始休息而勾组、写训练记录或自动归档；刷新可恢复，后台不承诺系统通知。
- 勾选前及归档前双重校验重量、次数和秒数；缺失/非数/负数/超限/非整数次数不计完成，允许取消已有勾选后修正。
- 增加可折叠热身和双进阶说明。连续两次达到上限且质量/余力合格再考虑最小档位，仅为保守实践规则，不称为自动个性化处方；腿部不强制追求增重。
- 不改变计划行映射、既有草稿、数据库或RLS；无新SQL。

## 依据与验证

- ACSM 2026公开摘要： https://acsm.org/resistance-training-guidelines-update-2026/ （个体化、主要肌群每周两次、增肌较高周量、无需普遍追求力竭）
- NSCA时间效率训练： https://www.nsca.com/education/articles/ptq/time-efficient-training/ （简单器械、主项组织与休息示例）
- 41项自动化测试：新增工作组校验/动作休息分类；真实UI测试覆盖计时不写记录、倒计时、结束休息与空重量不能勾选。既有同步、历史CRUD、会话恢复、时区及报告回归继续通过。
