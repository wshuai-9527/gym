## 小块瑜伽垫

| 动作 | 每次起始安排 |
|---|---|
| 平板支撑 | 2×20–60秒，无历史时30秒；有历史优先参考实际时长 |
| 负重保加利亚分腿蹲 | 每侧2×8–12 |
| 罗马尼亚硬拉 | 2×8–12 |
| 屈膝侧桥 | 每侧2×15–30秒，前臂与膝盖垫住即可 |
| 站姿单侧哑铃静止保持 | 每侧2×20–40秒，首次轻重量自行确认 |

新计划不安排全身仰卧卷腹、地面臀桥、死虫；旧动作仍可在历史中编辑记录。臀腿训练起点4组，核心6组，单侧不乘2。核心提前以便落实，支撑保持自然呼吸、不力竭，垫子或脚下不防滑则停止。站姿保持是单侧负重抗侧屈练习，不是卷腹的等效替代，也不声称可以局部减脂。小垫与器械条件下优先稳定完成；腹肌可见度仍取决于体脂等因素。

站姿保持记录格式`5kg*20s`，计入时间与计时工作组，不算成20次，也不产生kg·次数。不得将划船或分腿蹲负荷套给此新动作。

动作依据参考：[Mayo核心训练](https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/core-strength/art-20546851)、[ACE单侧负重携行](https://www.acefitness.org/resources/everyone/exercise-library/358/suitcase-carry/)。静止保持是为有限空间采用的简化，2组与20–40秒为可调整起点，并非研究确认的个人最优剂量。

## 进阶与数据

余力反馈不会再自动证明动作质量、无痛；另选动作状态后才保存明确确认标记。旧版本的正向反馈布尔字段不能单独触发进阶。连续最近两次完整、同重、全部达上限且明确动作稳定无痛、余力至少2次时，建议最多0.5kg且≤5%；预填仍保留原重量，由用户根据器械档位决定。较小重量无合适档位就维持组数，先巩固动作。疼痛暂停提醒；明确动作失控或持续低于下限时保守减量。依据[ACSM 2026](https://doi.org/10.1249/MSS.0000000000003897)，这些是产品决策规则，不宣称为个体最优处方。

版本59仅用于新草稿。旧进行中草稿保留版本与计划快照，行号不映射到新动作；数据存储键、登录会话、认证与云端权限不变。
