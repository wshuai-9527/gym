## 动作与计划

单臂哑铃划船代替新模板的双臂俯身划船，不把两者历史改成同一个动作。俯身反向飞鸟是后肩动作；站立向两侧抬臂是中肩侧平举。胸前夹合是胸飞鸟，不能只凭“飞鸟”两字合并。站立哑铃夹胸不作为默认胸部训练。

默认目标为增肌和一般力量，非经过评估的个体处方。新模板：

| 日   | 动作与工作组                                                |
| ---- | ----------------------------------------------------------- |
| Push | 平板卧推3、上斜卧推2、坐姿推肩2、站姿侧平举3、过顶臂屈伸2   |
| Pull | 高位下拉3、单臂哑铃划船每侧3、坐姿俯身反向飞鸟3、靠腿弯举3  |
| Legs | 保加利亚分腿蹲每侧3、罗马尼亚硬拉3、臀桥2、提踵3、平板支撑2 |

减少拉日重复水平划船；原壶铃摆动是髋铰链爆发动作，本次用可控负重的 RDL 作为基础髋铰链，保留原摆动历史。单侧记录每侧组数一次；外部负荷不擅自翻倍。

近28天云端记录7次力量、3次篮球。缺失日不是休息；若这是完整日志，PPL让单个肌群重复刺激的频率偏低，优先考虑每周2–3次全身训练，而非增加孤立动作。当前仍提供用户熟悉的PPL轮转，不把3天轮转误画成必须每天练。

ACSM 2026立场声明支持规律高努力抗阻、覆盖主要肌群；更高周组数通常有利于增肌，但不是人人必须立即达到10组的硬门槛。用约2次余力作为可执行起点，不声称这个RIR对所有人最优；同重量稳定达到次数上限再小幅加重。

来源：https://pmc.ncbi.nlm.nih.gov/articles/PMC12965823/ （doi:10.1249/MSS.0000000000003897）；动作区分参考ACE运动库与肩部研究，表面肌电不等于长期增肌效果。
