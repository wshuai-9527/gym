# V54：大屏手机与持久登录体验

- 对 440 CSS px 的 iPhone 16 Pro Max 竖屏宽度增加布局规则：18px 边距、50px 训练输入/完成目标、16px以上输入字号；保留顶部与底部安全区。添加 Apple 主屏幕元信息。
- 保留 Supabase SDK 的 persistSession 与 autoRefreshToken，沿用原有默认存储键，避免升级清掉已有会话。已登录时隐藏密码表单并显示设备登录说明。刷新令牌不重建同账号训练页面。
- 退出使用 local scope，避免退出一台设备导致其他设备也失效；退出失败不切换本地档案。未保存明文密码，不增加公开写权限，不修改 RLS，不引入 service_role。
- Safari 与主屏幕安装可能使用不同存储上下文，分别首次登录；不能承诺浏览器清理数据、撤销会话或修改密码后仍可免认证。现有代码已开启会话持久化，不能把一直显示的表单当成实际会话失效的证据。
- 没有数据库 SQL 或认证服务端配置变更。自动恢复、无密码调用、TOKEN_REFRESHED 不重绘、仅退出本设备以合成会话测试验证；不能代替用户真机续期测试。
